JKS Sketch — command language

Click the canvas to set the starting corner (it snaps to existing corners, then to the grid), then type walls into the command line and press Enter. Up is north on the page. Several commands can be typed on one line.

R40 L12.5 U28 D6Wall right / left / up / down by that length.
R40'6 R40'6" R40-6Feet and inches (40 ft 6 in). In metre mode this is converted to metres.
R40'6-1/2" R40'1/2Fractional inches (40 ft 6½ in, 40 ft ½ in). Decimal feet work too: R40.54.
R10U5Diagonal wall: 10 right and 5 up in a single wall (a bay, a clipped corner).
R40~5 R40~-5Curved wall: 40 corner to corner, the middle of the curve 5 out of the room (~-5 bows into it). On an open line, + bows to the left.
R40~r25 C~r20Curved wall by radius (25) instead of rise. Any wall can curve, including the closing one: C~5. A half-circle bay: R12~6.
R20~a31.4 R20~d90Curved wall by arc length (measured along the curve) or by arc angle (degree of curvature). R12~d180 is a half circle.
17>45 17<30 17>Turn: 17 long, turning right (>) or left (<) 45° off the line of the previous wall. No angle = 90°. Walls at odd angles without trigonometry.
U= L=Run up (left…) until level with the start, so the closing wall comes out square. For a field sketch with one dimension missing.
U* R*Run up (right…) until the wall meets an existing wall, or one of this area's own.
CWClose along existing walls: from the last corner, follow the walls already drawn back to the start. An addition needs only its own walls: start on the building (click a corner, or mR10), type the new walls, end on the building, CW. The traced walls' dimensions are hidden, since the building already shows them.
20@135Wall of length 20 at 135° (0° = right, 90° = up, counter-clockwise).
N45-30E120.5Survey bearing N 45°30′ E, 120.5 long (for lot lines). S12E, N89-59-30W etc.
mR10 mU4 m3@45Move the start point without drawing — e.g. a garage that starts 10 ft along the house wall.
CClose back to the start. The status bar reports the closing wall so a sketch that doesn't close is caught.
EEnd as an open line (a fence, a lot line, a wall that is not a room).
25.5 then →Number-pad drawing: type a length and press an arrow key; the wall is drawn at once.
Enter on an empty lineClose the area (3+ corners).
Backspace on an empty lineRemove the last wall.
EscCancel the area being drawn / clear the selection.
Ctrl+Z / Ctrl+YUndo / redo.
Arrows (empty line)Nudge the selection by the grid snap; Shift = ×10.
Delete (empty line)Delete the selection.
Ctrl+A / Ctrl+C / Ctrl+VSelect everything shown / copy / paste. With one level shown, paste puts the copy on that level in place: copy the main floor, show Upper, paste.
Select toolClick to select; Shift+click adds; drag on empty space draws a fence around what to select. Click a dimension to hide it (or show it again).
Mouse wheel / right-dragZoom / pan. In Draw mode you can also click out corners; hold Shift to keep a wall square.

Doors, windows, symbols

Pick a kind, width and (optional) height under Doors, windows, symbols, then with the Door/Window tool click a wall: the opening is centred where you click (snapped to the grid). Truck dock door (default 9'×10') and Grade-level overhead door (12'×14') get a size tag outside the wall (DH 9'×10', GL 12'×14') and are counted per building. Select the area to edit an opening: kind, wall, centre distance from the wall's first corner, width, height, swing out instead of into the room, and ⇄ to hinge at the other jamb. Openings move, rotate and mirror with their area and never change an area. Click a symbol in the palette, then click the plan to place it (keep clicking for more). Symbols are drawn at real size; select one to rotate it (⟲ ⟳ or any angle) or resize it.

Pages

Page in the toolbar: + adds a page (site plan, each building, each floor), Rename, ✕ deletes one. Each page is its own drawing; totals and areas.json cover every page. Each sheet is headed with the title and page name, the Site name (or the address when there is none) and "Page 2 of 3". Copy on one page and paste on another to start from the same outline, in place.

Cold and semi-cold storage

Set Storage (under Next area before drawing, or under Selected) to Semi-cold storage or Cold storage. Those sections are hatched on the plan and totalled on their own, apart from the main (heated) building area, everywhere totals appear.

Year built and ceiling height

Select an area (a section) to note its Year built and Ceiling ht: one height, or several separated by commas (16, 24'6). Tick details under Label to show them on the plan; they also appear in the calculations, the printed table and areas.json.

Levels, library, labels

Show picks one level: the others are hidden, new areas go on that level, and SVG/PNG/Print export just that level. Library… edits the area categories (code, label, counts toward building area, default factor, fill). Label chooses what each area's label shows. Interior / fence line is a category for lines that aren't measured; an open line (E) becomes one. Label text in the panel lets the Label tool place a room name with one click. Rotate… turns the selection, or the whole sketch, by any angle.

Separate or combined square footage

Every area shows its own size. To report adjoining areas as one total, give them the same Combine as name (e.g. GLA): the plan then shows each one's name and a single combined total, and the table and areas.json carry the combined figure as well as each part. Leave it blank to keep an area separate. Set Combine as under Next area to apply it to everything you draw next.

Tracing a hand sketch

Image… loads a photo of the field sketch under the drawing. Calibrate: click both ends of a wall whose length you know, then type that length — the image is scaled to match. Move drags it into place; the ° box rotates it. The underlay is never exported.

Outputs

Save writes an editable .sketch.json. SVG/PNG/JPG/Print give the clean plan for Schedule B. Every export is a real page: the paper and orientation (less a 0.4" margin), or Report figure (6.5 × 9", no margin, to drop into a letter-size report at full size). Leave the scale box blank and the plan, title and table are fitted to that page in both directions; or enter a scale (1" = 10', or 1:100 in metres). min … pt is the smallest text on the finished page (10 pt by default); everything else scales up from it. Place a PNG or JPG at its true page size and its text is that size too; dpi sets the image resolution. A dimension too long for its wall at that size is shortened, or left off with a warning. SVG, PNG and JPG are of the page shown; Print (and Save as PDF) makes one sheet per page. areas.json records every area with building, level, category and size in both sq ft and m². File all of them into the job's dropzone/.

Area library

The categories areas are drawn in. Code can show on the plan (Label: code). Counts and Factor are what a new area of that category starts with; each area can still be changed on its own. Changes apply to this sketch; Save as my default makes new sketches start with this list too.
